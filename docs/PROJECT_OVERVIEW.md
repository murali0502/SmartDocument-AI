# Project overview

SmartDoc AI is a local-first document intelligence project. Its NCM methodology ties concept mentions, graph assertions and answers to immutable source evidence. The English-first CPU profile is the baseline.

Phase 1 delivered the local development scaffold, a web status application, and the first relational migration. Phase 2 adds local upload, durable jobs and evidence-preserving format extraction. Phase 3 builds structural hierarchies, stable chunks and exact-span evidence from those results. Phase 4 adds local English linguistic annotations and optional discriminative models for embeddings and text inference. The [roadmap](DEVELOPMENT_ROADMAP.md) describes the gated delivery sequence and the [methodology](NCM_METHODOLOGY.md) defines evidence anchors and the planned NCM pipeline.
