# Project overview

SmartDoc AI is a local-first document intelligence project. Its NCM methodology ties concept mentions, graph assertions and answers to immutable source evidence. The English-first CPU profile is the baseline.

Phase 1 delivers the local development scaffold, a web status application, and the first relational migration. The [roadmap](DEVELOPMENT_ROADMAP.md) describes the gated delivery sequence and the [methodology](NCM_METHODOLOGY.md) defines evidence anchors and the planned NCM pipeline.
